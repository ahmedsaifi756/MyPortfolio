02 / How I engineer

AI interprets.
Code verifies.
Rules control.

I don’t treat an LLM response as a trusted instruction. I treat it as an input that needs to earn its place in the workflow.

The goal is not to add AI everywhere. It is to use AI where language understanding helps, and deterministic logic where consistency, money, security or policy matter.
